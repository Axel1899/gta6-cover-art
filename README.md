## About this entry

This entry is a GTA-style cover art maker built around your own material. Load a photo, arrange it across comic panels, shape the composition, add a caption, and export the finished cover as a PNG at 1080x1080, 1080x1350 or 1920x1080.

Everything runs locally in the browser and works fully offline. The artwork and lettering are original creations for this entry; it uses no game assets.
